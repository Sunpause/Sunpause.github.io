# 常州的苏超之旅

《新生实践课》网页设计作业。主题是“常州队在江苏省城市足球联赛（苏超）的两个赛季”，
以及常州把主场赛前的时间变成“新能源之都”展示窗口的这件事。

> 共 6 个页面：主页 + 球场 / 两届 / 球迷 / 新能源 / 图集。
> HTML + CSS + 一小段 JavaScript（导航、滚动动效、图片灯箱）；含 4 段自剪短片，
> 所有图片、视频都是本地文件，断网也能看。

---

## 一、怎么打开

1. 把 `MyWeb` 文件夹复制到任意位置（例如 `D:\MyWeb`）。
2. 双击 `index.html`，用 Chrome / Edge 打开。
3. 不需要安装环境，也不需要联网。

> 全站使用相对路径。只要 `index.html`、`image`、`web` 三个位置的相对关系不变，
> 整个文件夹搬到哪里都能正常显示。

## 四、视频说明

四段视频都是**现场拍摄的真实画面，保留原声**（球场环境、解说与人声），没有配乐、没有配音：

| 文件 | 内容 | 时长 | 画幅 |
| --- | --- | --- | --- |
| `hero-loop.mp4` | 常州主场看台与比赛画面，首屏循环 | 8 秒 | 852×480 |
| `highlights.mp4` | 常州队赛季五佳球 | 40 秒 | 852×480 |
| `opening-film.mp4` | 2026 苏超决赛赛前展演 | 26 秒 | 852×480 |
| `tech-reel.mp4` | 自动驾驶两轮电动车方队（苏超赛场） | 21 秒 | 480×852 竖版 |

素材来自球迷与媒体在现场拍摄、公开发布的视频，仅截取片段用于课程作业展示，未作二次创作；
画面角落的原始水印已做遮挡处理。

技术上是标准的 HTML5 `<video>`：

```html
<video controls preload="metadata" poster="...jpg">
  <source src="...mp4" type="video/mp4">
</video>
```

首屏背景用了 `autoplay muted loop playsinline`（浏览器只允许静音自动播放），
左下角“声音”按钮可以取消静音；其余三段带 `controls`，点播放就是现场原声。

## 五、和示例站点的区别

示例站点是 7 张 2848×1600 的整页大图，文字全“焊”在图里，用图片热点跳转，单张最大 8 MB。

这个版本：

- 改成 6 个真正的网页，文字可以选中、复制、搜索；
- 用普通的 HTML 导航，没有图片热点，手机上也能正常看；
- 图片重新裁切压缩，另加 2 段自剪短片；
- 增加了“新能源”一页，记录常州赛前的科技展示。

技术上用了 HTML 基础标签、CSS 的 flex / grid、表格样式、媒体查询、
`:hover` 过渡和 HTML5 的 `<video>`，没有用框架，也没有写 JavaScript。

  据新华日报 / 光明网、中国江苏网、常州晚报等公开报道核对整理。

  产业集聚度全国第三，据新华日报报道；开幕式 290 台机器人、40 辆卡丁车、
  10 月 11 日《智启绿茵·常创巡游》等细节据常州晚报报道。
- 字体使用系统自带字体，无网络字体。

## 七、发布到 GitHub Pages

1. 新建仓库（Public），把 `MyWeb` 文件夹**里面的内容**传到仓库根目录（根目录要有 `index.html`）。
2. 仓库 **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main` / `/ (root)`。
3. 等 1—2 分钟，访问 `https://用户名.github.io/仓库名/`。

> 视频文件较大，GitHub 单文件限制 100 MB，这里最大 5 MB，没问题。
